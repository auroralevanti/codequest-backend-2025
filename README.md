## Installation

```bash
$ npm install
$ copy .env.template and rename to .env (configure your PostgreSQL database URL)
```

## Running the app

```bash
# development
$ npm run start:dev

# production mode
$ npm run start:prod
```

## Swagger 

Go to http://localhost:3000/api

## Test

```bash
# unit tests
$ npm run test

# e2e tests
$ npm run test:e2e

# test coverage
$ npm run test:cov
```
